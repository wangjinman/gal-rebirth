# 重生·轻逆袭 (Re: Second Chance)

> 一款 Steam 平台的独立 GAL 游戏，主题：重生 + 轻逆袭 + 恋爱

## 📖 项目简介

**一句话卖点**：如果人生能重来一次，你会选择弥补遗憾，还是拥抱新的可能？

**游戏类型**：视觉小说 / 恋爱模拟 / 重生穿越  
**游戏时长**：约 10 小时  
**美术风格**：日系精致立绘，温馨日常感  
**尺度定位**：擦边向（暗示、情绪张力、情感亲密戏，不露点）

## 🎮 故事概述

35 岁的陆鸣在母亲去世的那天晚上，骑车赶往医院的路上遭遇车祸。

再次醒来，他发现自己回到了高三教室，距离高考还有 32 天。

这一次，他只有一次机会。

|------|------|------|----------|
| **林晚棠** | 女主角·同桌 | 温柔内敛、细腻敏感 | ★★☆ |

| **沈听雨** | 神秘角色 | 神秘莫测、温柔中带锋利 | ★★★★★ |

## 🛠️ 技术栈

- **引擎**：Ren'Py 8.0+
- **语言**：Python + Ren'Py Script
- **美术**：AI 辅助生成 + 人工精修
- **音乐**：Suno AI 辅助创作
