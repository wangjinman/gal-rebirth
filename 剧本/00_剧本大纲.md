## 一、创作原则

### 1.1 叙事基调

| 阶段 | 基调 | 情绪曲线 |
|------|------|---------|
| 序章 | 沉重 → 震撼 → 爽感 | 低开高走，情绪冲击+重生爽感 |
| 第一章 | 轻松 → 暗流 → 小高潮 | 轻喜剧为主，带悬疑，爽感点缀 |
| 各女主线 | 甜虐交织 → 爆发 | 前期甜→中后虐→高潮爆发→结局治愈 |
| True Ending | 仪式感 → 情感释放 | 高走，情感总爆发 |

### 1.2 重生爽感设计（核心原则）

**"重生不是为了悲伤回忆，而是为了爽快地改变。"**

重生题材的核心魅力不是"我好惨"，而是"我知道未来，所以我能改变"。剧本必须体现三重爽感：

```
【爽感一：信息差碾压】
- 陆鸣知道谁会背叛、谁会离开、哪件事会出问题
- 他不是预言家，而是"已经经历过的人"
- 关键场景：利用前世记忆做出正确选择，让NPC震惊

【爽感二：弥补遗憾的满足】
- 每个遗憾碎片被解锁时，都要有情绪释放感
- 玩家通过陆鸣弥补了自己心中的"如果当初..."
- 关键场景：告白成功、兄弟和解、母亲健康

【爽感三：蝴蝶效应的惊喜】
- 一个小改变引发大不同的连锁反应
- 玩家感受到"命运真的被改变了"
- 关键场景：移民取消、父亲戒赌、敌人变朋友
```

**爽感实现 Checklist（每个重要场景必须满足至少一项）：**
- [ ] 是否有"信息差碾压"的体现？
- [ ] 是否有"弥补遗憾"的情感释放？
- [ ] 是否有"蝴蝶效应"的连锁反应？

### 1.2.2 爽感专属化设计（各线主打类型）

每条女主线的核心爽感类型不同，不可通用，需要根据人设定制：

```
【林晚棠线 — 主打：信息差碾压 + 蝴蝶效应】
爽感公式：前世记忆（我知道未来） → 主动出击（做出前世不敢做的事） → 命运被改写（她没去日本）
代表场景：
  - 雨中送伞（前世错过，主动弥补）
  - 救活多肉（展示"我了解你"的信息差）
  - 说服林父（蝴蝶效应：说服一人 → 整个家庭改变 → 移民取消）
核心差异：爽感来自"我提前知道，所以我能改变"

【苏念卿线 — 主打：遗憾弥补 + 救赎治愈】
爽感公式：她的伤痛（我知道她的故事） → 温柔守护（做出前世没做的事） → 互相治愈
代表场景：
  - 发现疤痕后不追问（尊重 + 建立信任）
  - 前男友骚扰时挺身而出（前世朋友做不到的事，这一世我来做）
  - 深夜阳台交心（前世错过深入交流，这一世补上）
核心差异：爽感来自"被看见、被理解、被守护"

【周芷晴线 — 主打：蝴蝶效应 + 反差萌互动】
爽感公式：她的孤独（我知道阳光下的阴影） → 主动靠近（做出前世没交集的事） → 打破她的外壳
代表场景：
  - 便利店雨夜交心（前世没有这个场景，主动创造）
  - 她吃醋竞争对手出现（前世零互动的她开始为你吃醋）
  - 打破"弟弟滤镜"告白（从学妹到恋人的身份转换）
核心差异：爽感来自"我是唯一看见她另一面的人"

【陈墨线 — 主打：救赎式遗憾弥补 + 深度情感共鸣】
爽感公式：她的压抑（我知道完美主义下的崩溃） → 不完美的陪伴（做出前世不可能的事） → 允许她不完美
代表场景：
  - 深夜图书馆发现她崩溃（前世从未走近，这一世我看见了）
  - 模拟考第二崩溃时接住她（前世无人接住，这一世我做那个肩膀）
  - 告白时告诉她"你已经够好了"（打碎她18年的枷锁）
核心差异：爽感来自"我爱你，不需要你完美"

【沈听雨线 — 主打：悬念揭秘 + 信息差最大张力 + 命运抉择】
爽感公式：她的秘密（我知道她来自未来） → 揭开谜底（做出超越命运的事） → 重新定义关系
代表场景：
  - 真相揭示（前世35岁才认识的恩人，原来一直守在身边）
  - 命运抉择（留下 or 离开——超越前世认知的选择）
  - 跨越时空的承诺（前世来不及说出口的感谢，这一世补上）
核心差异：爽感来自"命运的真相比想象更动人"
```

### 1.3 擦边暗示写法规范（Steam安全指南·按人设分风格）

**核心原则："情绪张力 > 肢体描写，暗示留白 > 直白展示"**

每条女主线的擦边暗示风格需要匹配人设，不可一刀切：

```
【四种擦边暗示风格模板】

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

【A型 · 林晚棠 — 若即若离·细腻留白型】
基调：温柔、心跳加速、欲言又止
关键词：发丝、侧脸、心跳、距离、月光
风格说明：她的感情是"慢慢靠近又退开"的华尔兹，擦边暗示要体现那种"差一点就碰到"的张力

A型参考写法（Day 14·天台）：
"夕阳把她的侧脸染成金色。
她低着头，小心翼翼地接过那盆多肉。
我忍不住伸出手，帮她把垂落的发丝别到耳后——
她的耳朵瞬间红了。
我收回手，心跳漏了一拍。
'晚棠...'
她的睫毛颤了一下，但没有躲开。
我们就这样对视着，夕阳一点一点沉下去。
谁也没有说话。
但有些事，不需要说出口。"

→ 核心手法：发丝、耳根红、对视不躲避——情绪升温但无肢体越界

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

【B型 · 苏念卿 — 成熟克制·深夜暧昧型】
基调：知性、深夜、微醺、成年人的克制与放纵
关键词：红酒、阳台、月色、微醺后的脆弱
风格说明：她28岁，有故事的女人，擦边暗示要体现"成年人之间的暧昧试探"，比少女线更有距离感但更撩人

B型参考写法（Day 15·深夜阳台）：
"她给我倒了半杯红酒，自己却喝了大半杯。
'你才18岁，喝这么多不好。'
她看着我，眼神有些迷离。
'18岁...真好。'
月光洒在她脸上，她看起来比平时更柔软。
'陆鸣，你觉得...被人喜欢是什么感觉？'
她的声音很轻，像是自言自语。
我没有回答。
只是伸出手，轻轻握了握她放在桌上的手指。
她的手指微微一颤，但没有抽开。
我们就这样，谁也没有说话。"

→ 核心手法：微醺后的脆弱、红酒氛围、指尖接触不越界——成年人之间的克制暧昧

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

【C型 · 周芷晴 — 阳光反差·突然安静型】
基调：反差、元气消失后的安静、脆弱
关键词：雨夜、眼睛红了、不再笑、安静
风格说明：她平时最闪亮，擦边暗示要体现"阳光熄灭后"的那一面，制造反差萌和心疼感

C型参考写法（Day 18·便利店雨夜）：
"她蹲在便利店的角落里，没有笑。
雨水顺着她的头发往下滴，打湿了她的校服。
'学长...你怎么知道我不开心？'
她的声音没有平时那股劲儿，闷闷的。
我蹲下身，和她平视。
'因为真正开心的人，不会用这种方式躲雨。'
她愣了一下，然后眼泪突然就掉下来了。
'我真的好累...'
她靠在我肩膀上，哭得像个小孩。
我没有推开她。
只是轻轻拍了拍她的背。"

→ 核心手法：元气消失的落差、雨夜脆弱、靠肩——心疼感优先于暧昧感

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

【D型 · 陈墨 — 冰山裂痕·珍贵瞬间型】
基调：难得柔软、第一次示弱、珍贵
关键词：哭、眼泪、颤抖、破防
风格说明：她是最难攻略的角色，擦边暗示要体现"难得的裂痕时刻"，每一次都很珍贵，克制但深刻

D型参考写法（Day 20·楼梯间）：
"她蹲在角落里，哭得浑身发抖。
我蹲下身，轻轻抱住她。
她僵了一下，然后整个人都软了下来。
'为什么...我已经这么努力了...'
她的声音断断续续，肩膀在抖。
我拍着她的背，什么也没说。
有些时候，语言是多余的。
她哭了很久，久到我的腿都麻了。
最后她抬起头，眼睛红红的，脸上全是泪痕。
'谢谢你...'
她的声音沙哑，但眼神第一次有了温度。"

→ 核心手法：抱头痛哭（点到为止）、破防瞬间——深度情感共鸣优先

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

【禁止的描写方式（所有类型通用）】
✗ 明确的身体接触描写（牵手、拥抱等需点到为止）
✗ 任何性暗示的直白表达

### 1.4 情感高潮设计标准

每条女主线必须在以下节点设计"情感爆发点"：

```
【标准高潮结构：321结构（弹性版）】

适用路线：林晚棠线、苏念卿线、周芷晴线（标准321）
适用路线：沈听雨线、陈墨线（精简/弹性321）

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

【标准321 — 林晚棠/苏念卿/周芷晴】

3个递进式小高潮（情感升温）：
├── 小高潮1：初遇心动（好感度突破30）
├── 小高潮2：危机初现（好感度突破60）
└── 小高潮3：深入了解（好感度突破80）

1个核心大高潮（情感爆发）：
└── 大高潮：生死/离别/告白抉择（好感度接近MAX）

2个余韵收尾（情感回味）：
├── 余韵1：告白/确认关系后的甜蜜日常
└── 余韵2：HE/TE的仪式感结尾

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

【弹性321 — 陈墨线】
适用原因：陈墨是高冷压轴线，3个小高潮节奏太密会显得廉价

精简结构（2+1+2）：
├── 小高潮1：深夜图书馆发现脆弱（Day 9）→ 好感度突破40
├── 小高潮2：崩溃救赎（Day 20）→ 好感度突破80 ★压轴大高潮
└── 大高潮 + 余韵合并：告白+理解"你已经够好了"（Day 25）

→ 删减理由：陈墨的防线太高，小高潮1太弱撑不住，大高潮才有足够的情感爆发力
→ 弹性原则："不是每条线都需要等距的节奏，有时候一把长弓比三把短弓更有力"

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

【弹性321 — 沈听雨线】
适用原因：沈听雨是隐藏悬念线，3个小高潮节奏会破坏悬念感

悬念前置结构（1+1+2）：
├── 前置悬念：初遇（Day 6）→ 好感度20，好奇心MAX
├── 悬念积累：多次偶遇+伏笔（Day 12-18）→ 好感度缓慢爬升至60
├── 大高潮+余韵：真相揭示+命运抉择（Day 21-24）→ ★★压轴爆发

→ 删减理由：沈听雨线的核心爽感是"揭秘"，过早的小高潮会提前释放情绪张力
→ 弹性原则："悬念线的节奏是'压弹簧'——压得越久，弹得越高"
→ 注意：沈听雨线需要扩展至90分钟（新增2-3个场景），详见第十章

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

【高潮场景 Checklist：】
- [ ] 大高潮是否有足够的情感铺垫（至少3个场景预热）？
- [ ] 大高潮是否有多重情绪叠加（紧张+感动+释放）？
- [ ] 结局是否有"余韵感"，让玩家回味？
- [ ] 大高潮是否与该线主打爽感类型一致？
```

### 1.5 文案差异化原则（避免套路感）

```
【重生文的常见套路 - 本作需规避】
✗ "这一世，我不会再让父母失望"（喊口号式）
✗ "前世我太懦弱，这一世我要当最强"（龙傲天式）
✗ 所有女生都倒贴、所有男生都是坏人（脸谱化）
✗ 开局就开挂，一路碾压（缺乏成长感）

【本作的正确打开方式】
✓ 陆鸣的改变是渐进的，不是一夜之间变成完美的人
✓ 他也会犹豫、也会犯错、也会偶尔想躺平
✓ 有些事他改变了，有些事他依然无力
✓ 真正的爽感来自"选择"而非"碾压"
```

### 1.5.2 陆鸣凡人感设计原则

**核心原则："他是重生者，不是全能者。他有信息优势，但也有人的弱点。"**

```
【陆鸣不是龙傲天的原因】
1. 信息差是有限的
   - 他只记得人生关键节点的结果，不记得完整细节
   - 他知道"林父会戒赌"，但不知道具体是什么时候、怎么戒的
   - 他知道"陈墨会崩溃"，但不知道导火索是什么

2. 改变是需要代价的
   - 主动接近林晚棠，可能引起其他女生的注意
   - 帮助苏念卿对抗前男友，可能会惹上麻烦
   - 蝴蝶效应是双向的——好变化和坏变化都可能发生

3. 人是有限理性的
   - 知道应该做什么，和能做到什么，是两回事
   - 他也会选择困难、惰性发作、临场慌乱
   - 前世35年的习惯，不是一朝一夕能改变的
```

### 1.5.3 陆鸣台词逻辑设计

**核心原则："重生者的台词要有'双关感'——表面是现在的话，深层是前世的话。"**

```
【陆鸣专属台词风格】

1. 信息差台词（双关）
   表面：描述当下的事
   深层：其实是在回应前世的遗憾

   例子：
   - "这盆多肉...我相信它能活。"（表面：鼓励多肉；深层：我相信你能度过这个难关/我能改变你的命运）
   - "你今天气色挺好的。"（Day 1和林晚棠的对话；前世他从未有机会这样说）
   - "你知道吗，这个场景我见过很多次。"（表面：随口一说；深层：他真的见过，这是前世最遗憾的瞬间之一）

2. 凡人感台词（自嘲）
   特点：偶尔的自我怀疑、不完美

   例子：
   - "我真的能做到吗...？"（关键抉择前的自我怀疑）
   - "前世的我，肯定会在这里退缩。"（用前世的失败衬托现在的勇气）
   - "算了，想太多也没用，先试试再说。"（偶尔的惰性，但最后还是行动了）

3. 成长感台词（渐进改变）
   特点：前期更内向、更犹豫；后期更坚定

   例子（林晚棠线递进）：
   - Day 1："没...没什么。"（回避她的目光）

### 1.5.4 陆鸣性格缺点设计

**核心原则："有缺陷的男主更有代入感，关键时刻的缺点要成为剧情的推动力。"**

```
【陆鸣的三大性格缺陷】

1. 选择困难症
   表现：面对多条线索时犹豫不决，错过最佳时机
   正面：谨慎，不会冲动犯错
   负面影响：有时候太慢，导致事情往坏方向发展
   剧情体现：Day 5林远事件中，如果玩家选择"再等等"，可能导致林远提前和家里闹翻
   → 这不是BUG，是设计——让玩家感受到"选择困难"带来的代价

2. 惰性残留
   表现：有时候想躺平，不想每次都冲在最前面
   正面：接地气，玩家能理解
   负面影响：有时候需要林远或女主推一把
   剧情体现：Day 15-16陆鸣有时会想"反正林父最终会戒赌，要不不管了？"——但最终他还是去了
   → 惰性和勇气的拉扯，是角色的成长空间

3. 临场慌乱
   表现：关键时刻会紧张、说错话、脸红
   正面：真实，增加喜剧效果
   负面影响：告白前夜草稿被林晚棠发现（Day 20场景）
   剧情体现：
   - Day 20告白准备场景：草稿被晚棠看到，慌乱掩饰
   - Day 17说服林父：原本准备好的话术，临场忘了一半，靠真诚硬撑
   → 慌乱是增加萌点和真实感的武器

【缺陷的使用规范】
- 缺陷是点缀，不是主线——不能让缺陷掩盖了主角的成长
- 每次缺陷发作后，必须有成长/改变作为回应
- 缺陷不能影响核心剧情走向——玩家可以通过选择克服缺陷
- 在女主面前展现缺陷，是增加亲密度的方式之一（反差萌）
```

## 三、重生规则边界

**重要说明：本章节定义了重生世界观的核心规则，是创作和逻辑判断的基准线。**

### 3.1 重生规则·六条边界

```
【重生规则定义】

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

【规则一：记忆碎片化】
重生者（陆鸣）只保留前世35年人生中的"关键节点结果"
不记得：完整的对话细节、精确的时间日期、大多数人的日常琐事
记得：高考成绩、母亲的病、兄弟的决裂、暗恋的结果——人生重大转折点

举例：
✓ 记得"林父后来戒赌了"（结果）
✗ 不记得"他具体什么时候戒的、怎么戒的、为什么戒"（过程）
✓ 记得"陈墨高考前崩溃过"（结果）
✗ 不记得"是第几次模拟考、她说了什么"（过程）

→ 创作意义：信息差是有限的，陆鸣不能像百科全书一样知道所有事
→ 玩家意义：陆鸣也需要"推理"和"试探"，不是开全图挂

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

【规则二：信息差优势窗口】
重生带来的信息优势会在32天内逐渐衰减
原因：他的存在本身就在改变历史，原先知道的事可能不再准确

举例：
- Day 1-7：信息高度准确（前世刚发生的事，他记得很清楚）
- Day 8-20：信息开始出现偏差（因为他的行动，历史开始偏移）
- Day 21-32：信息模糊（重大节点还在，但细节可能完全变了）

举例：
✓ Day 1 他确定"林晚棠一定会去日本"（因为前世就是）
? Day 14 他不确定"林父会不会提前改变"（因为他已经开始行动了）
✗ Day 25 他无法确定"高考作文题目"（因为蝴蝶效应已经改变了很多事）

→ 创作意义：不能用信息差碾压一切，有些事必须靠"这一世的选择"而非"前世的记忆"
→ 爽感设计：利用"时间窗口"——越早利用信息差，效果越好；越晚越需要真实行动

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

【规则三：仅此一次】
重生只有一次机会，且不可逆转
- 陆鸣只有一次重生机会（"仅有一次"是故事的情感基础）
- 这意味着：有些事他只有一次机会做选择，没有读档重来的余地
- 但在游戏层面：玩家仍然可以读档——这是"元叙事"的设计，玩家知道但主角不知道

举例：
✓ 林晚棠线的告白：陆鸣只有一次机会说出口（但玩家可以读档尝试不同选项）
✗ 母亲生病的危机：陆鸣只有一次机会在32天内解决（错过就没有了）

→ 创作意义：主角的"有限重做"和玩家的"无限读档"形成有趣的元叙事张力
→ 陈墨线特别注意：必须在Day 32前完成，否则"母亲病发"的蝴蝶效应会破坏其他线

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

【规则四：蝴蝶效应·双向性】
每个改变都会产生连锁反应——可能变好，也可能变坏
- 蝴蝶效应的方向取决于"陆鸣的行动"，而非自动向好
- 好消息：主动出击可以改变命运
- 坏消息：错误的行动可能让事情变得更糟

举例：
✓ 好蝴蝶效应：说服林父戒赌 → 家庭完整 → 移民取消（林晚棠留下）
✗ 坏蝴蝶效应：过早暴露"知道未来" → 被怀疑是疯子 → 社交信任危机
? 意外蝴蝶效应：帮林晚棠解决了家庭问题 → 她对你好感大增 → 但同时她开始依赖你 → 失去独立性

→ 创作意义：蝴蝶效应不是单向的好事，要设计"副作用"
→ 沈听雨线特别注意：她的存在本身就是最大的蝴蝶效应，她的离开或留下会改变所有人的命运

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

【规则五：蝴蝶效应·不可逆】
一旦改变，无法恢复原状（但在游戏内可以读档）
- 这是情感设计的基础：每一个选择都有重量
- 主角没有后悔药吃（但玩家有）
- 这个"遗憾感"是推动剧情的情感动力

举例：
✓ 如果陆鸣选择不告白，林晚棠会按前世轨迹去日本（无法挽回）
✗ 如果陆鸣提前干预母亲的治疗，但她身体还是不好（可能失败）
→ 创作意义："不完美"比"完美"更有戏剧张力——有些事尽力了也不一定成功

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

【规则六：重生代价·陆鸣的心理负担】
重生不是免费的——陆鸣承受着"双重时间"的心理压力
- 他同时活在"18岁的身体"和"35岁的记忆"里
- 他要假装正常，但内心装着35年的遗憾和焦虑
- 他会对"不重要的事"（考试、人际关系）变得异常淡定，对"重要的事"异常敏感

情绪设计举例：
- 高考模拟考试（Day 10-15）：他不在乎分数（前世滑档他知道过程不重要了）
  → 但在别人眼里，这是"学渣突然不关心成绩"的奇怪行为
- 林晚棠送他一支笔（前世没发生过）：他激动得睡不着
  → 但在别人眼里，这只是"普通的日常互动"
- 母亲叫他早点睡：他的眼眶瞬间红了（因为前世她走的时候，他还在熬夜加班）

→ 创作意义：重生者的"不正常"反应，是制造情节张力的素材
→ 也是陆鸣"凡人感"的核心来源——他不是神，他只是个背着太多记忆的普通人
```

### 3.2 重生规则的剧情约束

```
【六条规则在创作中的应用约束】

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

【约束一：不能用信息差碾压一切】
✓ 可以用："我记得这件事的结果"
✗ 禁止用："我记得完整的细节/对话"
→ 解决方式：当陆鸣需要某个信息时，他应该"隐约记得"而非"完全知道"

【约束二：陈墨线的32天硬限制】
✓ 时间窗口：Day 8-32
✗ 禁止延伸：任何导致超过Day 32的事件链都是逻辑漏洞
→ 特别注意：陈墨线最终告白必须在Day 26-30内完成，留给结局章Day 31-32

【约束三：蝴蝶效应的意外性】
✓ 每个重大改变都要设计"副作用"
✗ 禁止：所有改变都自动向好（太龙傲天）
→ 解决方式：沈听雨线作为"最大蝴蝶效应"线，专门探索这个主题

【约束四：重生者的心理真实性】
✓ 陆鸣可以对"不重要的事"异常淡定
✓ 陆鸣可以对"前世没发生的事"异常激动
✗ 禁止：陆鸣对所有事都"完美处理"（缺乏成长感）
→ 解决方式：用陆鸣的性格缺陷（选择困难、惰性、慌乱）制造起伏

【约束五：记忆碎片作为信息补充机制】
✓ 记忆碎片是解锁"过程细节"的奖励，而非一开始就知道
✗ 禁止：陆鸣直接说出完整的未来事件
→ 解决方式：碎片7/20 = 兄弟决裂真相；碎片12/20 = 陈墨崩溃导火索
```
