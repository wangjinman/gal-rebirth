## 一、创作原则

### 1.1 叙事基调

| 阶段 | 基调 | 情绪曲线 |
|------|------|---------|
| 序章 | 沉重 → 震撼 | 低开，情绪冲击 |
| 第一章 | 轻松 → 暗流 | 轻喜剧为主，带悬疑 |
| 各女主线 | 甜虐交织 | 前期甜，中后虐，结局治愈 |
| True Ending | 温暖治愈 | 高走，情感释放 |

### 1.2 对话风格

- **主角陆鸣**：内敛但不沉闷，偶尔毒舌，内心戏丰富
- **系统旁白**：幽默吐槽担当，以「旁白」或「系统君」形式出现
- **对话节奏**：日常对话轻快简洁，情感对话细腻有力
- **擦边处理**：情感表达含蓄但真实，用情绪张力而非肢体描写

### 1.3 关键场景模板

每个重要场景包含：
```

地点：XXX
时间：XXX
出场人物：XXX
核心事件：XXX
情感目标：XXX
关键对白：（示例）
Flag触发：XXX
```

## 三、序章：死亡与重生

**游戏时长**：约30分钟  
**核心功能**：建立世界观、引出重生设定、奠定情感基调

### 3.1 场景1：死亡（5分钟）

```
【场景】都市夜景·车祸现场
时间：深夜
出场：陆鸣（35岁）、救护人员（NPC）

【剧情流程】
1. 画面：雨夜城市车流，快递员陆鸣骑着电动车穿梭
2. 电话响起：医院通知母亲抢救无效
3. 情绪：陆鸣崩溃，闯红灯
4. 画面一转：刺眼的车灯 → 金属撞击声 → 屏幕黑

【关键对白】
陆鸣（内心独白）：
"我这辈子...到底在做什么？"
"妈，对不起，我还是没能让你骄傲..."
"如果能重来一次..."

【系统提示】→ 选择界面
「重新开始」
```

### 3.2 场景2：重生醒来（10分钟）

```
【场景】南城一中·高三（7）班教室
时间：下午·阳光刺眼
出场：陆鸣（18岁）、林晚棠（背影）、同学（NPC剪影）

【剧情流程】
1. 陆鸣猛然惊醒，发现自己在教室
2. 窗外是初夏的阳光，黑板上写着"距离高考还有32天"
3. 他看向旁边的座位——林晚棠正在认真做笔记
4. 前世记忆如潮水涌来：他认得这个下午，这就是"那个下午"
5. 陆鸣看向手背——那里没有任何伤疤（前世车祸留下的）
6. 他意识到：我真的重生了

【关键对白】
林晚棠："陆鸣？你怎么脸色这么差？是不是又熬夜了？"
陆鸣（内心独白）："这个声音...我有多少年没听到过了。"

【系统君旁白】
"恭喜你，主人公。你获得了人生重来的机会。"
"但是——根据老套的剧情设定——你只有一次机会。"
"32天后就是高考，改变命运的窗口期只有一个月。"
"请问：你打算怎么度过这重来的32天？"
```

### 3.3 场景3：回家确认（10分钟）

```
【场景】陆鸣家·傍晚
时间：放学后
出场：陆鸣（18岁）、陆母

【剧情流程】
1. 陆鸣冲回家，推开门
2. 陆母正在厨房做饭，回头笑着说"回来啦，洗洗手准备吃饭"
3. 陆鸣看到母亲健康的模样，眼泪夺眶而出
4. 陆母慌了："怎么了？是不是在学校被欺负了？"
5. 陆鸣抱住母亲，压抑着说"没事...只是做了个噩梦"
6. 陆母温柔地拍着他的背

【关键对白】
陆鸣（内心独白）：
"妈还活着...她还是这么健康..."
"上一世，她是在我28岁那年走的。那之前她受了三年的苦。"
"这一次，我一定不会再让她受罪。"

陆母："傻孩子，噩梦醒了就好。妈给你做了你最爱吃的红烧排骨。"
```

### 3.4 场景4：前世记忆碎片（5分钟）

```
【场景】陆鸣房间·深夜
时间：深夜
出场：陆鸣（18岁）

【剧情流程】
1. 陆鸣躺在床上，无法入睡
2. 脑海中开始闪回前世的"遗憾记忆碎片"
3. 碎片1：毕业典礼上，林晚棠笑着和所有人合影，唯独没有和陆鸣说上话
4. 碎片2：父亲在工厂事故中受伤，家里的经济支柱倒塌
5. 碎片3：高考失利，滑档到三本
6. 碎片4：最好的兄弟林远，在某次争吵后决裂
7. 碎片5：母亲躺在病床上，握着陆鸣的手说"对不起，妈拖累你了"
8. 陆鸣猛然睁眼——他坐起来，看向窗外的月亮

【系统君旁白】
"记忆碎片已解锁 5/20"
"遗憾弥补值：0/200"
"解锁更多碎片，可以获得改变命运的关键信息哦~"

【关键决定·序章结尾】
系统提示：你的重生已经开始了。接下来，你想优先做什么？

选项A：「先搞清楚现状」→ 调查一下现在是什么时候，还有哪些事没发生
选项B：「先去看看她」→ 林晚棠...这次我不会再错过
选项C：「先想办法赚钱」→ 前世记忆告诉我，家里会有一场经济危机

【Flag记录】
- 序章_选择_A/B/C → 影响第一章开局倾向
- 序章_完成 = True
```
