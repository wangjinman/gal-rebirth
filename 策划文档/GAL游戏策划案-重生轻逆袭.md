## 一、项目概述

### 1.1 基本信息

| 项目 | 内容 |
|------|------|
| **游戏名称** | 《重生·轻逆袭》（Re: Second Chance） |
| **游戏类型** | 视觉小说 / 恋爱模拟 / 重生穿越 |
| **目标平台** | Steam（Windows / Mac） |
| **定价区间** | ¥28 - ¥38（早鸟折扣） |
| **游戏时长** | 约10小时（单周目4-5小时，全女主+TE约10小时） |
| **美术风格** | 日系精致立绘 + 柔和光影，强调"温馨日常感" |
| **尺度定位** | 擦边向（暗示、情绪张力、情感亲密戏，不露点不过审） |
| **语言** | 中文（简体中文优先，可扩展日语/英语配音） |

### 1.2 一句话卖点

> **"如果人生能重来一次，你会选择弥补遗憾，还是拥抱新的可能？"**

### 1.3 目标受众

- **核心用户**：18-30岁男性GAL玩家，熟悉日系恋爱游戏套路
- **泛用户**：对"重生文"感兴趣的网文读者、喜欢治愈系剧情的女性玩家
- **回避群体**：反感NTR、厌恶"炒股"式攻略的玩家（需在商店页明确标注）

### 1.4 差异化定位

| 维度 | 本作 | 同类常见做法 |
|------|------|------------|
| 重生设定 | 重生到高考前1个月，有限逆袭时间窗口 | 重生到小学/初中，慢慢逆袭 |
| 逆袭程度 | "轻"逆袭——成绩提升有限，主攻人际关系破局 | 学霸系统、全方位碾压 |
| 恋爱节奏 | 每条线独立完整，不强制全通 | 必须攻略所有人才解锁真结局 |
| TE设计 | 多线结局后解锁"命运共同体"TE | 单线True Ending |

## 二、世界观设定

### 2.1 核心世界观

**重生规则**：
- 主角在35岁时因意外身亡，死后意识回到高考前1个月（18岁）
- 重生带有**"记忆碎片"**——仅记得关键人生节点的结果，不记得完整细节
- **仅有一次重生机会**，无法再次逆转

**核心冲突**：
> "我知道未来会发生什么，但我只有30天。"

### 2.2 故事背景

**时间线**：现代中国（2020s），二线城市

**主角身份**：
- 姓名：陆鸣（可自定义）
- 身份：高三学生，成绩中上，性格内向，存在感低
- 家庭：普通双职工家庭，父亲为工厂技术员，母亲为超市店员

**前世遗憾**（游戏内逐步揭示）：
1. 未能告白暗恋三年的同桌 → 她在毕业后去了异国，再未相见
2. 与最好的哥们因误会决裂 → 至死未能和解
3. 高考失利滑档到三本 → 学历歧视贯穿整个职场人生
4. 母亲在他28岁时病逝 → 没能好好陪伴最后的时光
5. 活成了"差不多先生" → 从未为自己争取过什么

### 2.3 故事基调

- **前期**：日常轻松，带轻喜剧元素
- **中后期**：情感深度逐渐加深，有泪点但不刻意煽情
- **底色**：励志治愈，强调"改变从当下开始"

## 五、系统设计

### 5.1 核心系统

| 系统 | 描述 |
|------|------|
| **好感度系统** | 每位女主独立好感度，影响对话选项和剧情走向 |
| **时间系统** | "30天倒计时"——每天可进行1-2个主要行动（推进主线或攻略女主） |
| **遗憾弥补系统** | 量化记录主角弥补前世遗憾的进度，影响TE解锁 |
| **记忆碎片系统** | 随游戏推进解锁主角前世的"记忆碎片"，揭示更多真相 |
| **Flag系统** | 关键选择自动记录，影响结局分支 |
| **玩家交互系统** | 关键选择分支、主动探索、QTE事件，增加玩家参与感 |

### 5.4 玩家交互系统（v1.1新增）

> **设计目标**：解决"玩家只需点击看剧情"的无聊感，让玩家在关键时刻做出选择、主动探索、触发特殊事件。

---

#### 5.4.1 关键选择分支系统

**设计原则**：选择不是"选A更好"，而是"你的选择定义了你是谁"。

```
【选择类型分类】

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

【A型 · 命运转折型】（影响核心剧情走向）

定义：重大抉择，会直接改变故事的结局分支
出现频率：每条线1-3次
设计要点：
- 选项之间没有绝对的"正确答案"
- 不同选择通向不同的情感体验（而非"好结局/坏结局"）
- 选择后的后果需要延迟显现，制造"蝴蝶效应"感

示例（林晚棠线·Day 13）：
┌────────────────────────────────────────────────────┐
│ 【移民话题·关键抉择】                               │
│                                                     │
│ 林晚棠：（眼眶泛红）"我妈在办移民手续...要去日本。" │
│                                                     │
│ 选项A：「我不想让你走」                              │
│        → 坦诚表达心意，好感度+15，但移民问题悬而未决 │
│        → 解锁后续"告白前置"剧情线                   │
│                                                     │
│ 选项B：「我们可以想办法」                            │
│        → 承诺一起解决问题，好感度+10               │
```
